# Proposta Comercial · Léia → Ezequiela

Proposta comercial digital para expansão da parceria entre **Léia** (criadora de conteúdo) e **Ezequiela** (corretora).

## 📋 O que está incluído

- **Produção de Vídeos** — 8 vídeos/mês por R$ 300 (+ R$ 15 por vídeo adicional)
- **Gestão de Social Media** — 3 posts/semana sendo 1 Reels por R$ 500/mês
- **Add-on: Stories Diários** — R$ 300/mês
- **Add-on: Gestão de Comentários** — a combinar

| Plano | Inclui | Valor |
|---|---|---|
| Plano Base | Vídeos + Social Media | R$ 800/mês |
| Plano Completo | Vídeos + Social Media + Stories | R$ 1.100/mês |

## 🚀 Como visualizar

### Opção 1 — Diretamente no navegador
Baixe o repositório e abra o arquivo `index.html` no navegador.

### Opção 2 — GitHub Pages
Acesse a URL do GitHub Pages deste repositório (se ativado).

### Salvar como PDF
Com a proposta aberta no navegador: `Ctrl + P` → Salvar como PDF.
